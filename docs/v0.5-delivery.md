## 2. 第一批：时间轴、习惯与分类

### 2.1 时间轴拖拽移动

- `TimeGrid` 新增 `onMoveItem(item, day, start)` 回调；
- 可拖动项：任务块与普通日程块；课程、全天项、DDL 不进入拖动状态；
- 拖动使用 `text/calendar-item` 标记来源，避免与「待排期任务」的 `text/plain` 冲突；
- 落点按 15 分钟对齐，保持原时长；
- 任务 → `scheduleTask`；普通日程 → `updateEvent`；
- 循环日程与 DDL 拖动时提示，不写入数据。

### 2.2 习惯编辑

- 习惯卡片新增「编辑」，回填名称、频率、颜色、模式、时长、写时间轴、分类、提醒时间；
- 保存走 `updateHabit`，只更新传入字段，不改 `id` / `createdAt`；
- 编辑态显示「保存修改」与「取消编辑」。

### 2.3 分类管理

- 设置页新增「分类管理」：新增、改名、删除、颜色选择；
- 新增与改名均做重名校验；
- 待办页新增分类筛选与行内分类下拉（`setTaskCategory`）；
- 删除分类二次确认，并提示任务会显示为未分类。

## 3. 第二批：普通日程编辑

- 日历侧栏中所有日程项都显示「编辑」（DDL 显示「改期」）；
- 普通日程表单支持标题、开始时间、结束时间、地点；
- 保存前校验结束时间必须晚于开始时间；
- `updateEvent` 的 patch 新增 `location`，可清空地点；
- 循环日程编辑作用于模板，保存后提示「循环日程已更新（影响所有实例）」；
- DDL 仍走截止时间单字段，并继续同步关联待办。

## 4. 第二批：热力图范围切换

- 复盘页新增范围选择：近 12 周 / 近 26 周 / 近 53 周；
- `heatmapWeeks` 参与 `eachDayOfInterval` 区间计算，摘要与格子同步更新；
- 热力图容器已有横向滚动，53 周时可直接滚动查看。

## 5. 第二批：通知自定义提前量

- `AppSettings` 新增 `reminderLeadMinutes`（默认 10）与 `habitGraceMinutes`（默认 5）；
- 设置页「系统通知」新增两个数字输入，失焦时保存；
- `useReminders` 把两项配置传给 `dueReminders`，规则纯函数不变；
- 新增单测覆盖自定义提前量（20 分钟）与自定义宽限（15 分钟）。

## 6. 第三批：目标与倒数日

### 6.1 数据模型与 schema v7

```ts
interface Goal {
  id: string;
  title: string;
  note?: string;
  targetDate?: string;   // yyyy-MM-dd
  progress: number;      // 0–100
  status: 'active' | 'done' | 'archived';
  categoryId?: string;
  createdAt: string;
  updatedAt: string;
  completedAt?: string;
}

interface Countdown {
  id: string;
  title: string;
  date: string;          // yyyy-MM-dd
  yearly?: boolean;
  note?: string;
  color?: string;
  createdAt: string;
}
```

- schema 升至 **v7**，新增 `goals` / `countdowns` 表与索引；
- 表由 `init_schema` 的 `CREATE TABLE IF NOT EXISTS` 创建，`migrate_v7` 只记录版本号；
- Rust 命令：`goal_list / goal_save / goal_remove / goal_clear`、`countdown_list / countdown_save / countdown_remove / countdown_clear`；
- Web 端使用 localStorage 等价集合，端口与关系表保持一致。

### 6.2 目标页

- 新增一级入口「目标」，页内分「目标 / 倒数日」两个 tab；
- 目标支持名称、目标日期、分类、备注；卡片显示进度滑块（0–100）与百分比；
- 支持「标记完成 / 恢复」与删除；完成时进度自动置 100 并记录 `completedAt`；
- 顶部统计进行中数量、已完成数量与平均进度。

### 6.3 倒数日

- 倒数日支持名称、日期、每年重复、备注；
- 剩余天数规则：今天为「就是今天」，未来显示「还有 N 天」，过去显示「已过去 N 天」；
- 每年重复的日期已过时自动换算到下一年同月同日；
- 列表按离今天由近到远排序；
- 今日页新增「倒数日」卡片，展示最近的 3 个未来事项。

## 7. 第四批：任务编辑、随想标签与周报导出

### 7.1 任务编辑

- 待办列表新增「编辑」，可修改标题、截止时间、优先级、预估分钟与备注；
- 新增 `updateTask` store 动作，标题为空时拒绝保存；
- 截止时间清空后 `dueAt` 置空，任务仍保留在列表；
- 分类仍可在行内下拉直接切换。

### 7.2 随想标签与搜索

- 随想支持标签：新建时可填逗号分隔标签，卡片上显示 `#标签` 并支持点击筛选；
- 每条随想可展开标签编辑，保存调用新增的 `updateNote`；
- 搜索框同时匹配正文与标签，实时过滤并显示结果数量；
- 标签去重，支持中英文逗号与空白分隔。

### 7.3 周报导出 / 导入

- 新增纯函数 `buildReviewMarkdown` / `parseReviewMarkdown`（`src/domain/rules/reviewReport.ts`）；
- 复盘页「复制复盘」改用同一生成函数，避免复制与导出内容不一致；
- 「导出 .md」通过 Blob 下载 `studydesk-复盘-<区间>.md`；
- 「导入 .md」读取文件，回填三个复盘问答；指标仍按当前数据实时计算，避免导入旧数据覆盖真实指标；
- 导入时忽略「（未填写）」项。

## 8. 第五批：循环日程深水区

### 8.1 循环规则编辑

- 日历侧栏编辑循环日程时，可修改频率（每天 / 每周 / 每月）、间隔、周几与结束条件；
- 每月规则保留原有的「每月某日」或「第几个周几」，不会因编辑丢失语义；
- 保存调用 `updateEvent` 新增的 `repeat` patch，提示「循环日程已更新（影响所有实例）」；
- 将频率改为「不重复」会清空 `repeat`，保留为普通日程。

### 8.2 单次覆盖（改本次）

- 循环 occurrence 增加「改本次」，可单独修改该次开始与结束时间；
- `ScheduleEvent.overrides` 以 `yyyy-MM-dd` 为 key 记录单次时间；
- `buildCalendarItems` 展开时优先使用 override 时间，其他实例不受影响；
- override 数据随 payload 落库，无需新增表或迁移。

### 8.3 跨天分段

- `buildCalendarItems` 将跨天事件按自然日拆成多段，次日显示「（续）」；
- 每段 id 追加日期后缀，保证日历 key 唯一；
- 时间轴可看到 22:00–次日 02:00 这类事件的次日部分；
- 次日凌晨段在 7:00 起始的时间轴上按最小高度显示（已登记限制）。

### 8.4 月视图落点配置

- `AppSettings` 新增 `monthDropHour`（默认 9）与 `monthDropMinutes`（默认 60）；
- 设置页新增「日历」区块，失焦保存并夹取合法范围（小时 0–23、时长 15–720）；
- 月视图拖入待办时按配置创建时间块，提示中显示实际落点与时长。

## 9. 第六批：数据一致性与冲突

### 9.1 排期冲突强拦截

- 待办排期检测到与课程/日程重叠时不再保存，直接提示占用项并中止；
- 冲突判断复用 `scheduleConflicts`，与日历展示口径一致。

### 9.2 DDL 事件与待办单事务

- Rust 新增 `save_deadline_pair`，在同一 `unchecked_transaction` 内写 `events` 与 `tasks`；
- 新命令 `deadline_save`，前端 `DatabasePort.saveDeadlinePair` → `RepositoryBundle.deadlines.savePair`；
- Web 端退化为顺序写入（无事务能力），桌面端保证原子性；
- 新增 Rust 测试 `deadline_pair_saved_atomically`。

### 9.3 删除分类清理引用

- 删除分类时同步清空任务的 `categoryId` 与习惯的 `categoryId`，避免悬空引用；
- 批量保存后再删除分类，列表与持久化状态一致。

### 9.4 时间轴循环 / DDL 拖动

- 循环 occurrence 拖动写 `overrides`（改本次），不修改整条规则；
- DDL 拖动调用 `updateEvent`，同步关联待办的 `dueAt` 与标题；
- 跨天「（续）」段不进入拖动，避免单次覆盖 key 错位；
- 课程与全天项仍不可拖动。

## 10. 第八批：专注与通知收尾

### 10.1 秒级精度与放弃统计

- `ReviewMetrics` 新增 `focusSeconds` 与 `abandonedSessions`；
- 复盘指标卡改为「专注时长 X分Y秒」，并新增「放弃次数」；
- 历史复盘记录同样显示秒级时长。

### 10.2 循环断点续跑

- 切换当前任务不再重置 `cycle`，循环轮次跨任务保留；
- 平台计时快照仍重置，避免显示上一任务的运行状态。

### 10.3 通知历史

- 新增 `notificationHistory` 规则：追加、读取、清空，最多 20 条；
- 提醒发送成功后写入 localStorage，设置页展示最近 5 条与「清空提醒历史」；
- 通知历史仅本机、仅应用运行期间产生。

### 11.3 习惯近 30 天热力图

## 13. 已知限制（已登记 backlog）

- 时间轴拖动不支持调整时长，只移动起始时间并保持原时长；
- 时间轴拖动不校验冲突；待办排期强拦截实测未生效，已登记 backlog；
- DDL 编辑时同步待办仍为两次写入，未事务化；
- 单次覆盖只改本次开始/结束时间，不改标题与地点；
- 跨天事件的次日凌晨段在 7:00 起始的时间轴上按最小高度显示；
- 循环规则编辑不提供每月「第几个周几」的可视化修改（保留原值）；
- 月视图落点配置只作用于拖入待办，不作用于拖动已有事件；
- 热力图长周期已自动滚动到最新，但未做缩放；
- 情绪/睡眠为自由文本，未参与指标聚合；
- 目标未关联任务/习惯，进度手动维护，无子目标与里程碑；
- 倒数日不参与日历、提醒与复盘统计；
- 每年重复按同月同日换算，2 月 29 日未特殊处理；
- 随想标签为自由文本，无标签重命名/合并管理；
- 周报导入只回填问答，不使用文件中的指标覆盖实时指标；
- Markdown 下载依赖 WebView 的下载行为，需桌面端手验；
- 通知历史仅保存在本机最近 20 条，点击通知跳转仍未实现。
