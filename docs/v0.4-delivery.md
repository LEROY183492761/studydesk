## 4. 任务分类

### 4.1 数据模型

```ts
interface Category {
  id: string;
  name: string;
  color: string;
  kind?: string;      // study / life / course / custom
  archived: boolean;
  createdAt: string;
}
```

`Task.categoryId` 已在 schema v4 预留，本轮接入 UI 与种子。

### 4.2 数据库 v6

```sql
CREATE TABLE IF NOT EXISTS categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  color TEXT,
  kind TEXT,
  archived INTEGER NOT NULL,
  payload TEXT NOT NULL
);
```

迁移 `migrate_v6` 记录版本 6；表本身由 `init_schema` 的 `CREATE TABLE IF NOT EXISTS` 创建，旧库启动即可用，不依赖 `ALTER` 顺序。

Rust 命令：`category_list / category_save / category_remove / category_clear`。

### 4.3 种子

- 独立标记 `studydesk.v1.seeded.categories`，不与全局 `seeded` 混用；
- 默认三类：学习、生活、其他；
- 从课表课程自动生成分类（当前 5 门课程 → 共 8 类）；
- 「重置演示数据」会清空分类并重新生成。

### 4.4 页面

- 待办新建表单增加「分类」下拉，默认「未分类」；
- 四象限卡片与列表卡片显示分类名；
- 复盘饼图按 `task.categoryId` 聚合，未设置分类时按任务标题兜底。

## 5. 习惯真实计时与饼图配色

### 5.1 习惯计时（任务化模式）

- 习惯卡片在任务化模式下提供「开始计时」，点击后复用平台 `FocusTimerPort`；
- 计时中每秒轮询 `focus.status()`，按钮实时显示「结束并打卡 · mm:ss」；
- 结束时 `focus.stop()` 拿到 `actual_seconds`，不足 1 分钟按 1 分钟计；
- `completeHabit` 先删除当日旧的打卡记录及其生成的任务/专注记录，再按真实秒数重新生成；
- 生成的专注记录 `startedAt = 结束时刻 - 实际秒数`，时间块与真实耗时对齐；
- 生成的任务带 `habit.categoryId`、`timerMode: 'stopwatch'`、`note: 实际 N 分钟`；
- 习惯创建表单新增「分类」下拉，默认未分类。

### 5.2 饼图稳定配色

- `computeFocusBreakdown` 新增可选 `categories`，label 取分类名、color 取分类色；
- 无分类或未匹配到分类对象时，使用标签哈希 `stableColor()` 从 6 色调色板取色；
- 同一标签在不同区间/不同排序下颜色固定，不再按聚合结果循环取色；
- 复盘页把 `categories` 同时传给当前区间与上一区间两次计算。

## 6. 系统通知

### 6.1 实现方案

- Rust 侧接入官方 `tauri-plugin-notification`（2.8.0），`notify` 命令由空实现改为真实系统 toast；
- 前端继续通过 `PlatformPort.notification` 调用，Web 端保留浏览器 Notification 降级；
- 设置页新增「系统通知」总开关（默认开启），关闭后所有提醒静默；
- 设置页提供「发送测试提醒」，便于一键验证桌面通知链路。

### 6.2 触发规则

| 触发点 | 时机 | 去重 key |
|---|---|---|
| 课前提醒 | 课程/日程开始前 10 分钟内且尚未开始 | `item:<id>:<date>` |
| 习惯提醒 | `habit.remindAt` 到点后 5 分钟内且当天未打卡 | `habit:<id>:<date>` |
| 专注结束 | 倒计时归零；有下一轮时提示休息时长 | 每次结束一次 |
| 休息结束 | 休息归零且将进入下一轮 | 每次结束一次 |

- 调度器 `useReminders()` 挂在应用根部，每 30 秒检查一次，跨天自动清空去重集合；
- 习惯创建表单新增「提醒」时间输入，卡片显示提醒时刻；
- 领域规则集中在 `src/domain/rules/reminders.ts`，有独立单测（4 项）。

### 6.3 已知边界

- 应用未运行时不会提醒（未做后台常驻或系统计划任务）；
- 提醒窗口为 5–10 分钟，错过不补发；
- 通知不支持点击跳转到对应课程/习惯；
- 已有习惯不能修改提醒时间（习惯编辑入口仍未做）。

## 8. 当前限制（已登记 backlog）

- 分类的编辑/删除没有页面入口（store 已有 `addCategory` / `removeCategory`）。
- 任务创建后不能改分类（没有任务编辑入口）。
- 待办列表没有分类筛选。
- 分类名称重复不校验。
- 习惯计时复用全局单例计时器，与专注页计时互斥（后启动会覆盖先启动）。
- 计时中刷新页面或切换路由会丢失「当前计时习惯」，后台计时仍在跑。
- 待办与日程在日/周视图仍不能直接拖拽排期，月视图仅支持拖入日期格。
- 应用未运行时不会产生系统通知，提醒错过不补发。
- 通知不支持点击跳转；已有习惯不能修改提醒时间。
- 普通日程编辑、DDL 双写事务、月视图落点配置仍为 v0.5。
