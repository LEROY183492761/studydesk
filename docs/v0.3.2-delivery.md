## 2. 数据模型

`ScheduleEvent` 新增：

```ts
repeat?: EventRecurrence | null;
exdates?: ISODate[]; // 跳过的 occurrence 日期
```

```ts
interface EventRecurrence {
  frequency: 'daily' | 'weekly' | 'monthly';
  interval: number;
  byWeekday?: number[];   // 0=周日 … 6=周六
  byMonthDay?: number;    // 每月 N 日
  bySetPos?: number;      // 每月第 N 个，负数表示倒数
  count?: number;
  until?: string;         // yyyy-MM-dd
}
```

数据库 v5 已预留 `repeat_json` / `exdates_json`，无需新增迁移。

## 3. 展开规则

`expandRecurrence` 支持：

| 频率 | 行为 |
|---|---|
| daily | 从起始日每 `interval` 天 |
| weekly | 从起始周每 `interval` 周，按 `byWeekday` 多选展开 |
| monthly | 每 `interval` 月，按 `byMonthDay` 或「第 N 个周X」计算 |

约束：

- `count` 从起始日计数（包含范围外 occurrence），与 RRULE 语义一致；
- `until` 与查询范围共同截断；
- 结果按日期升序，最多 500 条保护。

## 4. 日历展开

`buildCalendarItems` 对循环事件：

1. 用模板事件的开始/结束时间提取时分；
2. 按查询区间展开日期；
3. 过滤 `exdates`；
4. 每个 occurrence 生成独立 `CalendarItem`，`id = event_<id>_<yyyyMMdd>`，`sourceId` 仍指向原事件。

这样月视图/周视图都能看到循环日程，且点击详情仍能回溯到原事件。

## 5. 表单与交互

日程表单新增重复面板（仅「日程」类型，DDL 不显示）：

- 重复方式 segmented；
- 每周：7 个星期按钮多选；
- 每月：方式切换 + 日期/第 N 个周几输入；
- 结束条件：永不 / 到某日 / 共 N 次。

详情列表对循环事件显示「跳过本次」，写入 `exdates` 后该次不再出现。

示例：每周二 19:20–20:55、地点 N112、标题「旁听数学课」、永不结束 → 周视图每周二自动出现，月视图每次一条。
