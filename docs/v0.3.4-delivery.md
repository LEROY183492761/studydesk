## 2. 数据模型

`Habit` 新增：

```ts
mode?: 'light' | 'task';   // 默认 light
timerMinutes?: number;     // 任务化打卡时长，默认 15
logToTimeline?: boolean;   // 是否写时间轴
```

`HabitLog` 新增：

```ts
generatedTaskId?: string;
generatedFocusId?: string;
```

数据库无需新迁移：`habits` / `habit_logs` 的 `payload` 已保存完整对象。

## 3. 打卡产出规则

`buildHabitCompletion` 纯函数统一生成：

| 配置 | 产出 |
|---|---|
| 轻量模式 | 仅 `habit_log` |
| 任务化模式 | `habit_log` + 已完成 `Task(source='habit')` + 实际时间块 `FocusSession` |
| 轻量 + 写时间轴 | `habit_log` + 实际时间块 |
| 任务化 + 关闭写时间轴 | 仍生成时间块（任务化默认计入） |

时间块回填到打卡前 N 分钟，`note` 为「习惯：名称」，进入时间轴实际层与复盘统计。

补卡（日期不是今天）时，时间块固定落在该日 21:00，避免补卡记录跑到今天。

## 4. 取消打卡

删除 `habit_log` 时：

- 若存在 `generatedTaskId`，同时删除对应待办；
- 若存在 `generatedFocusId`，同时删除对应专注记录；
- 列表状态同步移除，不残留孤儿数据。

## 7. 当前限制（已登记 backlog）

- **打卡不是真实计时**：按配置时长直接回填，不是从开始到结束的实际耗时。
- **任务化生成的任务不可单独编辑**：目前随打卡创建/删除，编辑入口未做。
- **补卡时间固定 21:00**：不做手动指定完成时刻。
- **习惯提醒未接系统通知**。
- **周报只复制**：Markdown 导出文件与「从 Markdown 读回」未做。
- 任务分类管理仍未做，饼图继续用任务标题兜底。
