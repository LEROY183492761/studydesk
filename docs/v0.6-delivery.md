# v0.6 交付说明：习惯管理优化

> 设计口径见 `docs/v0.6-habits-design.md`。本轮把习惯从「二元打卡」扩展为「可累计数量、可设单位、可绑定目标」的量化习惯。

| 项 | 状态 |

## 2. 数据字段

### Habit

- `unit`：打卡单位，默认「次」；
- `dailyTarget`：每日目标量，默认 1；
- `unitMinutes`：每单位折算分钟（可选，用于时间轴）；
- `goalId`：绑定目标（可选）。

### HabitLog

- `value`：本次完成量（原字段语义扩展）；
- `unit`：本次单位快照；
- `recordedAt`：本次打卡时刻；
- `minutes`：本次折算分钟。

### Goal

- `habitId`：绑定习惯；
- `targetAmount`：目标总量；
- `autoProgress`：由习惯累计自动计算进度。

**schema 不变**：新增字段全部写入现有 `payload` JSON，仍为 v7，无需迁移。

## 3. 计算规则

| 指标 | 分子 | 分母 | 说明 |
|---|---|---|---|
| 目标型环比 | 当日/周期实际完成量 | 目标量（`dailyTarget` 或 `goal.targetAmount`） | 封顶 100% |
| 任务型环比 | 今日已打卡任务量（Σ value） | 今日累计任务量（`dailyTarget`） | 封顶 100% |
| 目标自动进度 | 周期累计量 | `targetAmount` | 绑定习惯时替代手填进度 |

- 当天累计 = 所有 log 的 `value` 按当前单位换算后相加；
- 同组换算：秒/分钟/小时、米/公里；其他单位只在同名单位间累加；
- 无法换算的记录计入「其他单位记录」，不强行相加；
- 时间单位打卡由计时器自动计算，非时间单位需用户输入数量。

## 4. 交互

- 顶部「+ 添加习惯」按钮 → 展开面板；编辑卡片复用同一面板；
- 轻量习惯：数量输入 + 单位选择 + 「打卡」，可连续多次打卡；
- 任务型习惯：`开始任务` → 实时计时 → `结束并记录`；时间轴记录「本次实际持续时长」，打卡记录显示「开始–结束 时长」，如 `08:36–09:37 1h1m`；
- 计时状态持久化：刷新/切页后若平台计时仍在运行，回到习惯页自动恢复「当前计时习惯」；
- 计时互斥：启动前检查全局计时器，已有计时在运行时提示并阻止覆盖；
- 小时单位保留两位小数：不足 1 小时记录为 `0.02h` 等，不再放大为 `1h`；
- 专注页快速新建任务支持选择分类与截止时间；
- 卡片显示「已完成/已打卡 分子/分母 单位 + 百分比」进度条；
- 7 天格子显示每日累计量，点击空白格可补记 1；
- 今日记录列表展示最近 3 条，可单条删除；
- 目标页新建目标时可选择绑定习惯并填写目标总量，进度自动计算且滑块只读。

## 6. 已知限制（已登记 backlog）

- 跨组单位不换算（次 ↔ 页），历史记录保留原单位并单独提示；
- 补记非当天的记录仍固定 21:00；
- 计时恢复依赖平台计时器仍处于运行状态；若在专注页结束计时，习惯页只清除恢复标记，本次不会自动入账；
- 任务化生成的任务需在待办页「已完成」筛选后编辑；
- 绑定习惯的目标删除习惯后会回退到手动进度；
- 目标自动进度不自动写入 `progress` 字段，展示层计算。
