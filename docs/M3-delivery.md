## 2. 实现要点

- 页面 `src/features/timetable/TimetablePage.tsx`；注册表把原「课程表」占位页替换为真实页面。
- 无课表时先展示学期创建表单；创建后进入周视图。
- 网格使用 CSS Grid：`44px + 7 列`，每行 1 节，课程安排按 `gridRow` 跨节显示。
- 当前显示周由 `viewWeek` 控制；「本周」按 `teachingWeekOf(now, termStartDate)` 计算。
- 课程安排通过 `isSessionActiveInWeek` 过滤（周范围 + 单双周 + hidden）。
- 新增 `saveTimetable` store 动作，写入 `TimetableRepository`（桌面 SQLite payload / Web localStorage）。
- 今日页与日历继续复用 `buildCourseItems`，课表数据自动进入既有视图。
