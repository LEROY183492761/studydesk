# StudyDesk 整体项目方案

> 本文是项目的全景蓝图与当前进度快照，整合 M0 → v0.4 的实现结果、架构决策与后续排期。
> 单期实现细节见 `docs/M*-delivery.md` 与 `docs/v0.x-delivery.md`，限制与延后项见 `docs/backlog.md`。

## 1. 产品定位

**一句话**：面向大学生的、本地优先的「时间管理 + 学务数据」一体化桌面日程软件。

**差异化**：不是又一个番茄钟，而是**让学务数据自动变成日程**：

| 学务输入 | 自动产物 |
|---|---|
| 课程表 | 周循环日程、课程分类 |
| 作业 DDL | 待办任务 + 日历 DDL 项（双向同步） |
| 考试 | 倒计时事件（M4） |
| 个人空闲节次 | 与空教室求交，推荐自习地点（M3） |

**体验主张**：计划层 / 实际专注层双轨时间轴；任务完成与专注记录自动汇入日/周复盘；全部数据只存本机。

**非目标**：多人协作与社交、复杂项目管理（甘特图/依赖）、通用笔记与网盘、生活服务（社区/二手/跑腿/外卖）、硬件健康监测。

## 2. 目标用户与核心场景

| 场景 | 用户动作 | 系统响应 |
|---|---|---|
| 早晨规划 | 打开「今日」 | 今日课程、DDL、待办、习惯一屏聚合 |
| 开始学习 | 专注页选任务 / 快速建任务 | 番茄倒计时或正计时，结束写入实际时间轴 |
| 课堂与作业 | 日程页建 DDL | 自动生成待办，改期/改标题双向同步 |
| 日常习惯 | 习惯页打卡或开始计时 | 轻量打卡 / 任务化生成待办 / 写时间轴 |
| 每周期复盘 | 复盘页看日/周指标 | 饼图、热力图、上期对比、Markdown 复制 |

## 4. 技术架构

```text
features/* (页面与交互)
      ↓ 只读 store / 调动作
state/appStore.ts (zustand：快照 + 领域动作 + 事件)
      ↓
domain/ (models 纯类型 / rules 纯函数 / selectors 聚合)
      ↓
data/ (RepositoryBundle → SQLite 或 localStorage)
      ↓
platform/ (Ports & Adapters：web.ts / tauri.ts)
      ↓
src-tauri/ (Rust：SQLite、FocusRuntime 计时、通知、窗口)
```

| 层 | 关键决策 | 理由 |
|---|---|---|
| 桌面壳 | Tauri 2（MSVC 工具链） | 安装包体积小、Rust 侧可直接落 SQLite 与计时 |
| 前端 | React 19 + TypeScript + Vite 6 | 组件化、类型安全、热更新 |
| 状态 | zustand 单 store + 领域事件 | 跨模块解耦，复盘/时间轴只订阅不侵入 |
| 数据 | SQLite 关系表 + `payload` JSON 列 | 可查询字段 + 灵活扩展，迁移成本低 |
| 图表 | 自研 SVG 环形图 / 热力图 | 不引图表库，样式与主题一致 |
| 测试 | Vitest 3 + React Testing Library + cargo test | 领域规则单测 + 页面冒烟 + Rust 迁移测试 |
| 平台抽象 | `PlatformPort` 端口 | Web 预览与桌面端共用业务代码，v1.1 悬浮窗/快捷键可直接复用 |

## 5. 数据模型

| 实体 | 关键字段 | 存储 |
|---|---|---|
| `Task` | 状态、优先级、截止、计时配置、四象限、分类、DDL 关联 | `tasks` 表 |
| `ScheduleEvent` | 起止、全天、类型（日程/DDL）、循环规则、跳过日期 | `events` 表 |
| `FocusSession` | 计划/实际秒数、模式、轮次、放弃标记、备注 | `focus_sessions` 表 |
| `Habit` / `HabitLog` | 频率、模式、时长、提醒时刻、分类；打卡日期与产出 ID | `habits` / `habit_logs` 表 |
| `Review` | 周期、指标快照、问答 | `reviews` 表 |
| `Category` | 名称、颜色、来源（学习/生活/课程/自定义） | `categories` 表 |
| `Note` | 内容、标签、转任务关联 | `notes` 表 |
| `Goal` | 标题、目标日期、进度 0–100、状态、分类 | `goals` 表 |
| `Countdown` | 标题、目标日期、每年重复、备注 | `countdowns` 表 |

**当前 schema：v7**（新增 `goals` / `countdowns` 表）。v6 时真实库核对：`schema_version=6`、`categories=8`（3 个默认类 + 5 门课程）；v7 由 Rust 迁移与 CRUD 测试覆盖。
**迁移铁律**：依赖新列的索引必须在 `migrate_vX` 的 `ALTER` 之后创建（v5 曾因顺序错误导致旧库启动 panic）。
**种子铁律**：新增实体使用独立种子标记（`seeded.habits`、`seeded.categories`），不与全局 `seeded` 混用。

## 7. v0.4 系统通知设计（已交付）

### 7.1 方案对比

| 方案 | 实现成本 | 可靠性 | 跨平台 | 维护成本 | 结论 |
|---|---|---|---|---|---|
| **A. `tauri-plugin-notification`（Rust 侧发送）** | 低：加插件依赖 + 包装 `notify` 命令 | 高：系统原生 toast，窗口最小化/后台仍可弹 | Windows/macOS/Linux | 低，官方插件 | **推荐** |
| B. 纯 Web Notification | 最低：只改前端 | 中：桌面 WebView 内权限与焦点行为不稳定 | 取决于 WebView | 中，需自行处理权限 | 只作为 Web 预览降级 |
| C. 自研 Windows toast | 高：winrt/windows crate 或 PowerShell 脚本 | 中：版本差异大、打包易漏 | 仅 Windows | 高 | 不采用 |

### 7.2 提醒规则

| 触发点 | 时机 | 去重 key |
|---|---|---|
| 课前提醒 | 课程/日程开始前 10 分钟内，且尚未开始 | `item:<id>:<date>` |
| 习惯提醒 | `habit.remindAt` 到点后 5 分钟内，且当天未打卡 | `habit:<id>:<date>` |
| 番茄结束 | 专注倒计时归零；有下一轮则提示休息 | 每次结束仅一次 |
| 休息结束 | 休息倒计时归零且将进入下一轮 | 每次结束仅一次 |

**总开关**：设置页「系统通知」，关闭后所有通知静默；Web 端首次触发时请求权限，授权后立即展示本次通知。

**已知边界**：应用未运行时不产生提醒（未做后台常驻/系统计划任务）；提醒窗口为 5–10 分钟，错过不补发。

## 8. 质量与验收标准

**运行方式**：开发用 `npm run desktop:dev`（加载最新源码）；成品用 `npm run desktop:build` 产出的 NSIS 安装包或 release 免安装 exe；`target\...\debug\studydesk.exe` 不能双击运行。

每轮交付必须实跑并记录证据：

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

Rust 侧：

```bash
export RUSTUP_HOME="$PWD/.toolchain/rustup"
export CARGO_HOME="$PWD/.toolchain/cargo"
export PATH="$PWD/.toolchain/cargo/bin:$PATH"
export RUSTUP_TOOLCHAIN=stable-x86_64-pc-windows-msvc
cargo test --manifest-path src-tauri/Cargo.toml --target x86_64-pc-windows-msvc --lib
```

桌面端验收：`npm run desktop:dev` 实跑；一次性种子/初始化逻辑必须「停进程 → 重启 → 查表计数」验证。
发布验收：`npm run desktop:build` 产出 NSIS 安装包与免安装 exe；**已打包产物不会自动包含后续源码改动**。

## 9. 风险与约束

| 风险 | 影响 | 应对 |
|---|---|---|
| 已打包产物落后于源码 | 用户误判「功能回退」 | 明确区分源码版本与安装包版本；需要新成品才重新打包 |
| Vite HMR 不重挂载应用 | 初始化/种子改动看似无效 | 停进程重启桌面会话后再验证 |
| Windows 通知需要应用身份 | Toast 可能不显示 | 使用官方插件，安装版以应用标识注册 |
| 网络策略限制 crates/二进制下载 | Rust 依赖安装失败 | 走可用镜像；依赖已在本地缓存时优先增量编译 |
| 循环高级编辑未实现 | 只能删除重建循环 | 已登记 v0.5 |
| 跨实体写非事务 | DDL 双写可能单边成功 | 已登记 v0.5 |
