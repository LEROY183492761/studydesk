## 2. 聚合口径

### 2.1 饼图

`computeFocusBreakdown`：

1. 只统计 `mode === 'focus'` 且开始时间落在区间内的记录；
2. 分组键优先级：`task.categoryId` → `task.title` → 「未归类」；
3. 按分钟降序，百分比按实际秒数计算；
4. 输出 Top 6 到图例，其余仍计入总计。

设计取舍：分类管理尚未实现，先以任务标题兜底，保证有数据可看；分类表接入后无需改图表逻辑。

### 2.2 热力图

`computeDailyHeatmap`：

- `focus` 口径：每日专注分钟；
- `all` 口径：专注分钟 + 课程分钟（来自 `CalendarItem.source === 'course'`）；
- 范围固定近 12 周（本周往前 11 周），不随复盘区间切换；
- 5 档：0、<30、<60、<120、≥120 分钟；
- 摘要：累计分钟、有记录天数、活跃日均。

## 3. 组件

| 组件 | 说明 |
|---|---|
| `DonutChart` | 用 SVG `circle` + `strokeDasharray/offset` 绘制扇区，支持空数据 |
| `Heatmap` | 按周分列、每列 7 天，cell 悬停显示日期与分钟 |
| `HeatmapLegend` | 少 → 多 5 档图例 |

均无第三方图表库，样式走 CSS 变量，主题切换自动适配。

## 4. 交互

- 复盘页日/周切换后，饼图与上期对比同步重算；
- 热力图口径 segmented 切换即时重绘；
- 日视图显示「今天」区间，周视图显示周一到周日；
- 无数据时饼图显示引导文案，热力图仍展示空白格子。
