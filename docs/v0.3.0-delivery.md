## 2. 数据模型

### Task 新增字段

```ts
timerMode?: 'countdown' | 'stopwatch' | 'none';
focusMinutes?: number;      // 倒计时单轮
breakMinutes?: number;      // 轮间休息
cyclesPlanned?: number;     // 预期循环次数
cyclesCompleted?: number;   // 已完成轮数
importance?: 'high' | 'low'; // 四象限预留
categoryId?: string;        // 饼图分类预留
linkedEventId?: string;     // DDL 双向关联预留
```

### FocusSession 新增字段

```ts
cycleIndex?: number;   // 第几轮番茄
abandoned?: boolean;   // 中途放弃
```

### 继承规则

`normalizePlan` 统一处理：

- 任务未配置时继承全局 `focusMinutes` / `breakMinutes`；
- 循环次数默认 1；
- 所有数值保证最小值 1。

页面只消费归一化后的 `PomodoroPlan`，避免任务与全局两套逻辑漂移。

## 3. 专注页

### 3.1 快速新建

在专注页直接创建任务，无需先去待办页：

- 任务名称、计时模式、番茄分钟、休息分钟、循环次数、备注；
- 创建后自动选中并绑定当前计时；
- 倒计时模式显示「番茄+休息 × 轮数 · 预计总时长」。

### 3.2 轮次状态机

```
focus 结束 → 写 FocusSession（cycleIndex）→ 更新任务 cyclesCompleted
          → 未达轮数：进入 break
          → 已达轮数：回到 idle
break 结束 → 未达轮数：进入下一轮 focus
          → 已达轮数：回到 idle
```

- 计时仍由 Rust `Instant` 驱动，前端 500ms 轮询；
- 轮次进度显示「第 2/4 轮」；
- 休息阶段可「跳过休息」；
- 「放弃」会记录一条 `abandoned=true` 的专注记录（实际时长 > 0 时），不计入完成。

### 3.3 预计时长

`totalPlannedMinutes` 计算：

```
focusMinutes × cycles + breakMinutes × (cycles - 1)
```

正计时与不计时返回 0，页面不显示预计时长。

## 6. 当前限制

- 正计时/不计时的记录展示与统计仍按分钟计，秒级精度未展示。
- 循环中途切换任务会重置当前轮次，不做断点续跑。
- 放弃记录暂未在复盘中单独统计。
- 计时结束尚未接系统通知。
- 快速新建的任务默认无截止时间与分类（分类在 v0.3.1 接入）。
